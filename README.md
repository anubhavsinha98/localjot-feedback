# Vokria feedback

Bug reports for [Vokria](https://localscribe-local-voice.anubhavsinha98.chatgpt.site), a local Mac dictation and meeting-notes app. This repository contains the public feedback tracker; application source is maintained separately in a private repository.

- [Report a bug](https://github.com/anubhavsinha98/localscribe-feedback/issues/new?template=bug_report.yml)
- [Search existing reports](https://github.com/anubhavsinha98/localscribe-feedback/issues)
- [Setup and troubleshooting](https://localscribe-local-voice.anubhavsinha98.chatgpt.site/setup.html)
- [Download updates](https://localscribe-local-voice.anubhavsinha98.chatgpt.site/#download)

Reports and comments are public and require a GitHub account. Share a short description and a synthetic example. Do not post audio, meeting transcripts/notes, dictation, coding prompts, credentials, personal file paths or other confidential information. Optional technical details can be previewed and copied from **Help → Report a bug…** in Vokria v0.13.3+; nothing is submitted automatically.

Use this tracker for general product bugs. [Report security vulnerabilities privately](https://github.com/anubhavsinha98/localscribe-feedback/security/advisories/new) through GitHub; never disclose them in a public issue. A GitHub account is required. Include a minimal synthetic reproduction and affected version, without audio, meeting content or credentials. A private contact for general support is still pending.

Maintainers use **needs-information**, **confirmed**, **in-progress** and **fixed** labels. Reports waiting for review carry **triage**. Fixed reports name the release version and link to its website download; updates are installed manually. Priorities: **P1** for blocked core workflows or data-integrity risks, **P2** for other reproducible bugs. These labels are workflow states, not response-time promises.
